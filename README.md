# 🌿 Avatar: Frontiers of Pandora 3D Mod

Based on AFR 3D: https://github.com/BerZerker96/6DOF-Head-Tracking-Mods-Hub

---

### 📦 Installation
1. Download **Ultimate ASI Loader** (rename to `dinput8.dll` or `dxgi.dll`): https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases
2. Place `AFOP-3D-6DOF.asi` and `3D-6DOF config.ini` into your game directory right next to `afop.exe`.

---

### ⚠️ Known Issues / Testing Notes
* **Frame Generation / DLSS-FG:** Extra generated frames can break left/right eye pairing. **Disable Frame Generation** for initial testing.
* **Camera Locking:** Cutscenes and Photo Mode may use separate camera objects. The mod targets and locks onto the primary persistent camera.
